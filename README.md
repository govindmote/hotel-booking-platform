# Saltwater House: Hotel Booking Platform

Week 2 project: Hotel Booking Platform (Hard). Built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Room cards with amenity badges, capacity and nightly pricing
- Search form for check-in/out dates and adult/child guest counts, with validation
- Live availability: rooms show Available, Booked for these dates, or Sleeps N only
- Live price calculation: nights x rate plus 12% tax
- Interactive filters: maximum price slider, amenity toggles, and sorting
- Booking confirmation modal (native `<dialog>`) with name/email validation and a booking reference
- A confirmed room is blocked for those dates, so it can't be double-booked in the session
- Responsive layout, keyboard-accessible controls, reduced-motion support

## How to run
Open `index.html` in any modern browser. No build step is needed.

## Skills demonstrated
Forms, room cards, interactive filters, responsive layout, UI/UX design, DOM events, date handling.

## Notes
Front-end demo only. Room availability is simulated and no data is sent anywhere.
